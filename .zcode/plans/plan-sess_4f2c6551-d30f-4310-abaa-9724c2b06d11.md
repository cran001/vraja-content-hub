# Content Hub Admin Restructuring — Stories / Calendar / Wallpapers Sections

## Context

The deployed hub lives on `origin/main` (DB-backed: Postgres + `pg`, node-pg-migrate migrations, Cloudinary uploads, JWT admin auth, single-page dashboard with a flat sidebar of 6 items). The current `master` checkout is a trimmed branch — **all work happens on a new branch off `origin/main`**. Master's JSON-file calendar endpoints stay untouched (Calendar is a placeholder anyway).

Today's sidebar (Gallery, Bulk Upload, Daily Darshan, Events Scheduler, Sponsorships, Categories) mixes every content type in one flat list. We'll restructure into **three collapsible sections** so content types never mix, and add a brand-new **Books** content type (a book = ordered pages, each page = image + title + optional text) for the app's Library.

Clicking a group header toggles expand/collapse (chevron rotates); the group containing the active tab auto-expands. Existing tab components are reused as-is — only navigation changes.

## 1. Database migrations (2 new files, node-pg-migrate convention)

`migrations/<epoch>_create-books-table.js`:
- `id` uuid PK `gen_random_uuid()`, `title` varchar(255) NOT NULL, `description` text NULL
- `cover_public_id` varchar(255) NULL, `cover_url` text NULL
- `sort_order` integer NOT NULL default 0, `is_active` boolean NOT NULL default true
- `author_id` uuid FK → admins ON DELETE SET NULL, `created_at`/`updated_at` timestamptz default now()
- index on `is_active`

`migrations/<epoch>_create-book-pages-table.js`:
- `id` uuid PK, `book_id` uuid FK → books **ON DELETE CASCADE** NOT NULL
- `page_number` integer NOT NULL, `title` varchar(255) NOT NULL, `body_text` text NULL
- `public_id` varchar(255) NOT NULL, `image_url` text NOT NULL, `thumbnail_url` text NOT NULL
- `is_active` boolean default true, `created_at`/`updated_at`
- UNIQUE `(book_id, page_number)`, index on `book_id`

## 2. Admin API routes (auth comes free — middleware already guards `/api/admin/*`)

**`src/app/api/admin/books/route.ts`** (flat-route convention, mirrors wallpapers route):
- `GET` — list books with `page_count` subquery, ordered `sort_order ASC, created_at DESC`
- `POST` — multipart: `title` (required), `description?`, `sort_order?`, optional `cover` file → Cloudinary folder `vraja-realm-books` → 201 with created row
- `PUT` — JSON `{ id, title?, description?, sort_order?, is_active? }` (COALESCE semantics like wallpapers)
- `DELETE` — `?id=` — destroy cover + all page assets on Cloudinary, delete rows (pages cascade)

**`src/app/api/admin/book-pages/route.ts`**:
- `GET` — `?book_id=` — pages ordered by `page_number`
- `POST` — multipart: `book_id`, files `image_0..N`, optional `title_0..N` / `text_0..N`; page numbers continue from current max; thumbnails via `cloudinary.url` 400x300 (same as wallpapers)
- `PUT` — JSON, two payload shapes: `{ id, title?, body_text?, is_active? }` for edits, or `{ reorder: { book_id, ordered_ids: [...] } }` to renumber pages in one call
- `DELETE` — `?id=` — destroy Cloudinary asset + row

## 3. Public API for the Android app

**`src/app/api/v1/books/route.ts`**:
- `GET /api/v1/books` → bare array of active books: `{ id, title, description, cover_url, page_count, sort_order, created_at, updated_at }` (snake_case to match Moshi conventions)
- `GET /api/v1/books?id=<uuid>` → `{ ...book, pages: [{ id, page_number, title, body_text, image_url, thumbnail_url }] }` — one fetch for the whole reader

## 4. Dashboard UI

**`src/components/dashboard/Sidebar.tsx`** — rewritten from `NAV_ITEMS` to `NAV_GROUPS` (group = `{ id, icon, label, children: NavItem[] }`). Group headers are buttons with chevron; expanded-group state via `useState`, auto-open when `activeTab` is inside a group. Sub-items use new `.nav-subitem` class (indented, slightly smaller).

**`src/app/globals.css`** — add `.nav-group`, `.nav-group-header`, `.nav-group-chevron` (rotate transition), `.nav-sublist` (collapsible), `.nav-subitem(.active)`; keep `--sidebar-w` coupling intact. No Tailwind utilities (not active in this codebase).

**`src/components/dashboard/BooksManager.tsx`** — book grid (`.img-card` style): cover, title, page count, active toggle (`.toggle`), Edit, Delete. "Add New Book" tab renders the creation form card (title, description, cover picker using `.drop-zone`). Clicking a book switches to the pages editor.

**`src/components/dashboard/BookPagesEditor.tsx`** — for one book: back-to-list header with book title/description edit; ordered page list (thumbnail, title input, text textarea, active toggle, ↑/↓ reorder, delete with confirm); add-pages drop zone (multi-select images, optional inline titles before upload). Reuses `useToast()`.

**`src/components/dashboard/CalendarPlaceholder.tsx`** — reserved empty-state screen: "Calendar management is coming soon — this space is reserved" using existing `.empty-state` classes.

**`src/app/dashboard/page.tsx`** — extend `TAB_META` (`books`, `add-book`, `calendar`), render new components, pass `setTab` for post-create navigation.
